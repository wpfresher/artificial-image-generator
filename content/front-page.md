# FAQ

**Do I need an API key?**
No — only for AI images and stock photos. Template images, including automatic featured images, are drawn on your own server with PHP's GD library. Stock photos need a free key from Unsplash, Pexels or Pixabay; AI images need your own OpenAI key.

**Which AI models can I use?**
OpenAI GPT Image 2.5 Flare (default), GPT Image 2.5 Sunburst and GPT Image 2. You bring your own API key and pay OpenAI directly — the plugin adds no markup.

**Will it create featured images for posts I already published?**
Automatic generation runs when a post is saved without a featured image. For older posts, open them in the block editor and use the AI Featured Image panel to generate one in a click.

**Does it work with Elementor, Divi or the Classic Editor?**
Yes. Automatic featured images work with every editor, because they run when WordPress saves a post. The Generate Image modal is also available in the Media Library for any builder.

**Does it work with WooCommerce?**
Yes. Generate and assign images on products from the block editor or the Media Library. With Pro, templates can show the price, sale percentage and rating.

**Do I need the free plugin to run Pro?**
Yes. Image Generator Pro is an add-on that extends the free Image Generator plugin (v1.8.0 or later), so install and activate both.
